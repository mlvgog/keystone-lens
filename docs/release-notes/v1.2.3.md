**Fixed the Settings window's close button so its full visible area responds to clicks.**

## Download

- **`KeystoneLens-Setup-1.2.3.exe`:** the installer (recommended).
- **`KeystoneLens-Portable-1.2.3.exe`:** a single exe, no install.
- **`SHA256SUMS.txt`:** checksums to verify the download.

The installed app updates automatically when automatic updates are enabled. The portable app links to the download page.

## Fixed

- The Settings close button could overlap the app's draggable title bar, leaving only part of the X clickable. Dialogs now receive clicks across their controls even when they overlap that title bar.

This fix was tested in a portable Windows development build. It adds no raider.io API calls.

The exe is not code-signed yet, so Windows SmartScreen may show "Windows protected your PC".
