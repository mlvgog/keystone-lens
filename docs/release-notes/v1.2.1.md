**A fix for the game addon: talents you get for free are no longer framed red.**

## Download

- **`KeystoneLens-Setup-1.2.1.exe`:** the installer (recommended). Installs for your Windows user only, with Start menu and desktop shortcuts and an uninstaller.
- **`KeystoneLens-Portable-1.2.1.exe`:** a single exe, no install.
- **`SHA256SUMS.txt`:** checksums to verify the download.

**Coming from 1.1.0 or 1.2.0?** The installed app updates itself and shows **Restart to update** in the title bar. The portable exe opens this page.

The exe is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

## Fixed

- **Game addon 1.1.1:** on the talent window, talents the game gives you for free were framed red as "most top players take this and you don't", even though you have them. This hit the first talent of a tree (for example Cloak of Shadows) and the first talent of your hero tree (for example Unseen Blade). They now show their pick rate without a frame. The red frame still marks popular talents you really skip.

The app replaces the addon copy it installed; type `/reload` in game afterwards. If you installed the addon yourself, Settings → Game addon offers the update.
