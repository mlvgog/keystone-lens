**Fixes for the game addon: popular builds no longer list a "Talent" with a number, and its menus are no longer see-through.**

## Download

- **`KeystoneLens-Setup-1.2.2.exe`:** the installer (recommended). Installs for your Windows user only, with Start menu and desktop shortcuts and an uninstaller.
- **`KeystoneLens-Portable-1.2.2.exe`:** a single exe, no install.
- **`SHA256SUMS.txt`:** checksums to verify the download.

**Coming from 1.1.0 or newer?** The installed app updates itself and shows **Restart to update** in the title bar. The portable exe opens this page.

The exe is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

## Fixed

- **Game addon 1.1.2:** in the `/kl` window's build pane, every build listed one talent you don't take, shown as "+ Talent" and a number, for example "+ Talent 99842". It was the hero tree choice itself, which the build already names. So your own build showed as "1 talent differ" instead of "your build", and the window said "Your talents are closest to Build 1 (1 differ)". Builds now compare only real talents.
- **Game addon:** the menus that open when you click a race or a gear slot in `/kl` were see-through, so the window's text showed through them. They now have a solid background.

The app replaces the addon copy it installed; type `/reload` in game afterwards. If you installed the addon yourself, Settings → Game addon offers the update.
