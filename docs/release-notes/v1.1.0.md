**Keystone Lens now updates itself.**

## Download

- **`KeystoneLens-Setup-1.1.0.exe`:** the installer (recommended). Installs for your Windows user only, with Start menu and desktop shortcuts and an uninstaller.
- **`KeystoneLens-Portable-1.1.0.exe`:** a single exe, no install.
- **`SHA256SUMS.txt`:** checksums to verify the download.

Coming from 1.0.0? Install this version by hand once: 1.0.0 can't update itself yet. Your settings, saved characters and cache are kept.

The exe is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.

## What's new

- **Automatic updates.** The installed app checks for a new version when it starts and every 6 hours. It downloads the update in the background and installs it when you restart or close the app. A green **Restart to update** button appears in the title bar when one is ready.
- **Your choice.** ⚙ Settings → **Updates**:
  - **Automatic** (default): as above.
  - **Only tell me**: shows the new version and installs it when you click.
  - **Off**: never checks on its own. "Check now" still works.
- **Portable exe.** It can't replace itself, so it tells you when a new version is out and opens its download page.

Update checks only ask GitHub for this project's newest release. See [PRIVACY.md](https://github.com/mlvgog/keystone-lens/blob/main/PRIVACY.md).
